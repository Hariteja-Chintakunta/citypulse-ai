# Project Documentation — CityPulse AI

The full project documentation is the Word document in this folder:

**[`CityPulse_AI_Project_Documentation_Hariteja.docx`](CityPulse_AI_Project_Documentation_Hariteja.docx)**

It covers, in order: problem statement, research (what exists today, the gap
CityPulse AI fills, why Hyderabad, the 10 wards plus Bachupally), solution (core journey,
workflow, modules by priority, citizen and admin views, grouped report
categories, Carpool, Pollution Map, Community Feed, Water Dashboard and AI
Assistant), technical approach
(stack, architecture, data model, API contract, AI and duplicate workflow,
repository structure, deployment plan, honest note about the live demo),
impact (for citizens, wards and the city), quality assurance (coverage,
TC01–TC20, demo narrative), limitations and responsible claims, team and
roles, execution plan (23–28 November 2026) and the submission checklist.
